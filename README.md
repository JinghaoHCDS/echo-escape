# 回声撤离 / Echo Escape

一个可直接打开运行的原创 Godot 3D 声音潜行原型。你在黑暗的单层建筑里靠脚步和鼓掌辨路，绕过巡逻怪物，唤醒深处的信标核心，再带着持续暴露位置的核心返回入口。

工程使用 **Godot 4.6.1 stable、类型标注 GDScript、Forward+**。提供源码工程与全部必要资源；运行不需要 Blender、C#、GDExtension 或第三方框架。没有将源码工程等同于安装包，导出与跨平台实测状态见 [验证记录](docs/VALIDATION.md)。

## 启动

在 Godot 4.6.1 中导入根目录的 `project.godot`，打开后按 **F5**。首次进入会显示操作说明，点击“进入静默建筑”开始并捕获鼠标。

macOS / Linux 终端也可运行：

```bash
bash tools/run.sh
```

脚本依次使用 `GODOT_BIN`、PATH 中的 `godot` / `godot4`、常见 macOS 安装路径。其他安装位置可显式指定：

```bash
GODOT_BIN="/absolute/path/to/Godot" bash tools/run.sh
GODOT_BIN="/absolute/path/to/Godot" bash tools/check.sh
```

Windows 可直接用 Godot 项目管理器导入，或在工程根目录运行 `Godot.exe --path .`。工程不依赖 shell 脚本才能启动。主场景是 `scenes/main.tscn`。

## 操作与目标

| 操作 | 按键 |
| --- | --- |
| 移动、观察 | WASD、鼠标 |
| 奔跑 | 按住 Shift |
| 鼓掌 | 鼠标左键 |
| 拾取信标核心 | E |
| 暂停、释放鼠标 / 恢复 | Esc |
| 胜负界面重开 | R，或点击按钮 |
| 开发照明、规则解释与传播网格 | F1 |

暂停界面可调视野角、鼠标灵敏度与播放音量。默认没有镜头摇晃，没有跳跃、战斗或背包。界面设置作用于本次会话，持久默认值在 `config/gameplay.json`。

1. 从入口向前进入声廊。小范围近地微光只能帮助避免盲撞；鼓掌可以看清更远处，但也会暴露发声位置。
2. 经中枢大厅或档案室，深入信标机房。怪物的低沉连续脉冲会揭示危险，并可能沿通路探测到你。
3. **首次被玩家鼓掌波及**后，核心保持暖色微光。近距离、无遮挡时按 E 拾取；未激活时不能取得。
4. 拾取后显示“信标已启动：怪物将持续追踪，返回入口撤离。”怪物此时持续获得你的位置。
5. 带着核心进入入口撤离区域即胜利。未携带核心时入口只给出缺少目标的提示。被一次有效挥击命中则失败；两种结果都能完整重开。

普通阶段听见你的脚步或鼓掌，怪物只得到**那次发声的位置**。它需要有限距离、视角、无遮挡视线，或自己的探测声确实抵达玩家，才能确认并追逐。没有新证据时沿最后已知位置追查，连续 5 秒没有有效证据会转入搜索，随后巡逻。拾取后的信标阶段独立允许持续定位。

身体接触不直接判负。怪物先抬起双臂并播放蓄力声，约 0.65 秒后挥击；攻击朝向在结束前 0.2 秒锁定。挥击有距离、方向和实体墙遮挡限制，之后恢复约 1 秒。侧移或拉开距离可以躲避。

## 声音与显形的实现边界

声音事件记录编号、来源、发生位置、时间、类型、强度、最大距离和显形时长。同一个事件分别驱动游戏听觉、环境显形和实际音频，播放音量不会改变怪物听觉。声波最多同时存在 24 个，播放节点固定池最多 16 个，结束的传播缓存会回收。

声学采用与关卡共用的 **1 米、四邻接通行网格**：只经开放格与门洞传播，距离为网格路径长度加发声点到起始格中心的距离，按距离 / 传播速度延迟到达并计算强度衰减。它是保守的 Manhattan 路径近似，可能比真实连续空间路径更长，也会有格子级的到达时间误差；不模拟反射、绕射、材质吸收或频谱变化，不是真实物理声学。低矮实心障碍也按二维阻挡处理，声音不从上方翻越。

环境显形读取同一传播结果，时戳保存在世界网格纹理中，转身不会重置。墙始终不透明并写入深度，所以黑墙也能挡住后方已显形的物体。环境约 2 秒平滑消退；怪物被波及后只短暂显示约 0.7 秒的**当前姿态**。静态设施的侧面从相邻可通行格读取显形，障碍顶部绑定最近的暴露格。

实际播放使用简化的 3D 距离衰减，不对耳机声音重做门洞传播延迟或真实墙体滤波；游戏判定与视觉传播仍使用通行路径。占位音由 `tools/generate_audio.py` 原创合成，随工程附带 WAV，正常运行不需要重新生成。需要修改音色时运行：

```bash
python3 tools/generate_audio.py
```

## 地图与视觉取舍

固定地图包含入口气闸、声廊、中枢大厅、档案室、信标机房，以及连接它们的宽门廊。声廊—大厅—机房—档案室形成环路，入口作为独立支路。具体格图、坐标及设施见 [关卡说明](docs/LEVEL.md)。

低面数风格由程序几何生成：实体墙、档案架、机房设备、六棱斜面设施、三重入口门肋和大厅悬吊横梁；怪物与核心也使用简单低面数几何。环境合并为一个 Mesh，共用显形 Shader，避免密集三角线框与大量独立材质。冷青回声、橙色危险和暖色核心承担不同信息，怪物还通过脉冲音色、节奏和抬臂动作提示危险。

F1 是开发视图，会打开正常照明并显示怪物状态、最后已知位置、证据和攻击原因、传播格与帧率；不改变听觉、视线、碰撞或攻击规则。传播图只显示通行范围、声波和玩家，不显示怪物实时小地图位置。

## 工程结构与调参

| 入口 / 模块 | 职责 |
| --- | --- |
| `project.godot`、`scenes/main.tscn` | Godot 配置与主场景入口 |
| `scripts/main.gd` | 会话装配、输入绑定、暂停、警报、胜负和重开 |
| `config/gameplay.json` | 集中的玩法与显示默认参数 |
| `scripts/player.gd` | 胶囊移动、重力、鼠标观察、按实际位移产生脚步 |
| `scripts/level_data.gd` | 房间和障碍、通行格、网格距离、四邻接寻路 |
| `scripts/level_builder.gd` | 从同一地图构建合并几何、实体碰撞、地标 |
| `shaders/environment.gdshader` | 世界显形、深度遮挡、近地微光、开发照明 |
| `scripts/sound_system.gd` | 有限声波池、传播时序、监听者、显形纹理、音频池 |
| `scripts/monster.gd` | 证据驱动状态机、视线、路径跟随、挥击与短时显形 |
| `scripts/objectives.gd` | 核心激活、无遮挡拾取、警报触发与撤离 |
| `scripts/game_ui.gd`、`scripts/debug_grid.gd` | 目标、冷却、交互、结果与调试说明 |
| `tests/`、`tools/check.sh` | 可执行轻量回归 |
| `assets/audio/`、`tools/generate_audio.py` | 随附合成音及可复现生成脚本 |

初始关键参数如下；修改 JSON 后重启游戏生效：

| 参数 | 默认值 |
| --- | --- |
| `walk_speed` / `run_speed` / `monster_speed` | 2.8 / 4.8 / 3.6 m/s |
| `walk_radius` / `run_radius` / `clap_radius` | 4 / 7 / 14 m |
| `clap_cooldown` / `propagation_speed` | 1.5 s / 10 m/s |
| `reveal_duration` / `monster_reveal_duration` | 2 / 0.7 s |
| `probe_interval` / `probe_radius` | 3 s / 7 m |
| `evidence_timeout` / `search_duration` | 5 / 5 s |
| `sight_range` / `sight_fov_degrees` | 8 m / 80° |
| `attack_windup` / `attack_recovery` | 0.65 / 1 s |
| `pickup_distance` / `exit_radius` | 2 / 1.45 m |
| `max_waves` / `max_audio_voices` | 24 / 16 |

地图尺寸、原始设施几何和格子坐标集中在关卡模块中，未做通用关卡编辑框架。项目使用 Git 管理源码与小型资源，忽略 `.godot/` 导入缓存、构建目录和临时文件。后续修改入口与不可破坏的规则见根目录 `AGENTS.md`。

## 检查与已知限制

```bash
# 导入工程，然后按阶段运行逻辑/物理回归。
bash tools/check.sh
bash tools/check.sh --graphics  # 加跑真实图形、混音、输入与完整流程

# 仅作无窗口启动冒烟检查。
bash tools/run.sh --headless --quit-after 120
```

**实际执行的检查、图形验证方式、实测性能和未验证项，以 [docs/VALIDATION.md](docs/VALIDATION.md) 为准。** 无窗口运行不能证明画面、声音输出或鼠标手感通过。1080p / 60 FPS 是优化目标，不是未经测量的性能承诺；工程默认 1920×1080 视口、1280×720 窗口。

原型只有一张地图、一个怪物和一个核心，无存档、程序化生成、真实麦克风输入、复杂声学或完整音频遮挡；没有复杂导航避让。Windows 与 macOS 是目标平台，未在某个平台运行的项目不会标作已验证。导出模板与安装包状态同样以验证记录为准，源码工程可直接交付运行。

机制受声音探索玩法启发；本工程布局、几何、Shader、脚本与合成音均为本项目制作，不包含《回声探路》的素材、地图、标识或代码。
