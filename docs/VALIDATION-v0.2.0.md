# v0.2.0 验证记录

执行日期：2026-09-17。Godot 4.6.1 stable，macOS 26.6.2，Apple M4（Apple9），Metal 4 / Forward+。初版记录保存在 [v0.1.0](VALIDATION-v0.1.0.md)，以下是本次连续声波修改后的实际结果。

## 本次修改

- 传播速度 **10 → 24 m/s**。开放空间中14米约0.58秒，前沿宽度1.1米，残留约2秒。
- 声学改为从声源出发的连续欧氏路径，遇实体墙经门洞和拐角绕行。怪物移动仍使用原有四邻接寻路。
- 画面按每个像素的世界坐标求到达时间，地面圆形、墙面圆弧；不由低面数三角面或1米格的更新决定显形。
- 监听者与GPU共用0.25米采样距离场及有效采样点的双线性插值，再合成高度距离。墙保持不透明深度遮挡。
- 最多24个声波层，保留至传播和残留都结束；距离缓存最多16份，音频仍为16节点固定池。

## 本机实测性能

1920×1080、正常AI和连续脚步/鼓掌、关闭截图开销的一次完整路线：**18.91108秒 / 2249渲染帧 = 平均118.9 FPS**，末段引擎计数119 FPS。[原始输出](v0.2-benchmark-output.log)。

连续距离模块本次测试：可见性图初始化3.444ms、加载阶段预计算采样865.078ms；20次移动声源的求路和纹理生成平均13.164ms，最大16.758ms。首次预计算放在关卡加载时，避免第一次鼓掌承担它的开销。这是本机有限样本，不是最低帧率或其他硬件性能保证。
