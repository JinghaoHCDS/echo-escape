# 原创关卡：静默信标设施

关卡唯一事实来源是 `scripts/level_data.gd`，`LevelData.new()` 自动构造数据。下面记录初始布局，修改关卡数据时应同步更新本说明。

## 拓扑与方向

```text
                 北 / -Z

          档案室 ←────────→ 信标机房 [核心]
             ↑                    ↑
        折角连廊               机房连廊
             ↓                    ↓
            声廊 ←──大厅门廊──→ 中枢大厅
             ↑                    [怪物出生]
          入口连廊
             ↓
         入口气闸 [出生 / 出口]

                  南 / +Z           东 / +X →
```

声廊、档案室、机房、大厅组成可双向通过的环路，入口是安全支路。去往机房有两条路线，取得核心后可以选择另一侧绕回，也可以利用宽厅中间障碍拉开距离。

## 实际 1 米占用格

## 房间与连接

表内格坐标区间均包含两端，世界包围范围则从最小格边界到最大格边界加 1。

| 房间 | X 格区间 | Z 格区间 | 设计作用 |
| --- | --- | --- | --- |
| 入口气闸 | 2–10 | 22–27 | 安全出生、最终撤离、辨认三重门肋 |
| 声廊 | 2–11 | 11–19 | 第一次练习回声，绕过档案架，选择去程 |
| 中枢大厅 | 15–27 | 13–24 | 怪物初始区域，足够侧移与绕障碍躲挥击 |
| 信标机房 | 24–33 | 2–9 | 深处目标，核心位于设备遮挡后的东北侧 |
| 档案室 | 10–19 | 2–8 | 环路另一侧，书架与折角切断视线 |

| 连接 | X 格区间 | Z 格区间 |
| --- | --- | --- |
| 入口—声廊 | 5–8 | 19–22 |
| 声廊—大厅 | 11–15 | 14–17 |
| 大厅—机房 | 25–28 | 9–13 |
| 机房—档案室 | 19–24 | 4–7 |
| 档案室—声廊 | 7–10 | 7–12 |

主要连接段宽约 4 m，门头装饰不缩窄地面通路。入口距离怪物初始区域超过初始探测范围，中间还有转角和墙体；怪物出生不对准入口。

| 设施 | 占用格 `(X, Z)` | 实体高度 | 识别 / 玩法作用 |

| 声廊档案架 | X 4–5，Z 14–16 | 2.45 m | 三道水平端饰、两侧可绕行，切断视线 |
| 中枢设备基座 | X 20–22，Z 17–19 | 1.90 m | 四侧可绕行，上方六棱斜面机体与悬吊十字梁 |
| 大厅次级设备 | X 25–26，Z 21–22 | 1.20 m | 提供局部绕行，低矮轮廓区别于主设备 |
| 档案室档案架 | X 13–15，Z 4–5 | 2.45 m | 两条通路与视线遮挡，突出房间方向 |
| 机房设备列 | X 28–30，Z 4–5 | 2.45 m | 竖向肋条、六棱顶盖，遮住核心直接视线 |
| 入口三重门肋 | Z 23.0 / 24.7 / 26.4 | 2.95 m | 撤离时可辨认的重复门框轮廓 |

表中设施的占用格先从通行网格移除，再生成相同范围的实体碰撞。装饰端饰只薄薄附着已有障碍边缘，悬吊件位于头顶，不形成额外未标注通路阻塞。所有装饰共用环境回声材质；没有永久发光的远距导向标志。

## 初始位置与巡逻

所有以下位置的 Y=0 表示脚底地面；玩家摄像机与核心的显示高度由各自模块设置。

| 对象 | 世界坐标 |
| --- | --- |
| 玩家出生 | `(6.5, 0, 25.5)`，初始面朝 `-Z` |
| 出口区域中心 | `(6.5, 0, 26.0)` |
| 怪物出生 | `(24.5, 0, 18.5)` |
| 信标核心锚点 | `(32.5, 0, 3.5)` |

巡逻顺序为 `(25.5,0,16.5)` → `(26.5,0,7.5)` → `(17.5,0,6.5)` → `(8.5,0,12.5)` → `(17.5,0,18.5)`，然后循环。路线通过网格寻路抵达各点，不直接穿越连接点之间的墙区。

## 后续修改的约束

- 修改房间、墙或设施占地时，改 `LevelData` 的 carve / block 数据；不要只改显示网格或只补碰撞。
- 保留一条环路、入口安全支路、足够侧移的宽厅，以及至少一个遮挡核心的设施。
- 寻路只走四邻接格心，重新规划从当前格心接入，避免斜切墙角。墙体碰撞是第二层保护。
- 声波距离与显形到达时间来自同一网格。墙面取外侧通行格，设施顶面取相邻暴露格的时间，不能因相机朝向变化重新“发现”空间。
- 每次修改后运行 `bash tools/check.sh`，并在图形环境用 F1 检查格图、墙体、设备与路径是否一致。图形和手感验证是否执行，应记录到 `docs/VALIDATION.md`。
